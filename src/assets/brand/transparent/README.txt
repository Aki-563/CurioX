CURIOX / transparent logo set / 22 November 2026

13 transparent variants, each supplied as SVG, vector PDF, and PNG:
- Symbol, horizontal, and vertical in black, white, and purple #9351F3.
- Horizontal and vertical with purple symbol + black or white lettering.

SVGs contain only outlined logo paths and no background rectangles. PNGs
have an alpha channel with transparent pixels. All PDFs have no painted
background; PDF viewers may display an unpainted page as white. Place or
import the PDF into a design document to use the background-free artwork.

curiox-transparent-artboards.pdf contains all 13 background-free artboards.
curiox-transparent-overview.pdf shows the same artwork over checkerboards.
Checkerboards belong to preview pages only; they are absent from the assets.
White versions are intended for dark surfaces.

Geometry, dot alignment, uppercase wordmark, proportions, and spacing are
identical to the approved final logo versions. Font lettering is outlined.
